Palma Verde — Open Streets: a complete open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car, steal vehicles, outrun the Verde PD's wanted system, and run five story jobs for the fixer Mara Solis — with traffic, pedestrians, a day/night cycle, a live minimap, synthesized sound and a save that remembers your haul.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under game/.
